# Adeies — πρόγραμμα αδειών iMentor Consulting

Αυτόνομη εφαρμογή (ανεξάρτητη από τις υπόλοιπες εφαρμογές του repository).

## Λειτουργίες
- **6 εργαζόμενοι σε 2 τμήματα**: Επιχορηγούμενα Προγράμματα (Μάνος, Χρήστος, Ελευθερία) και Οφειλές (Σοφία, Στέλλα, Βάλια). 22 εργάσιμες ημέρες ετησίως ο καθένας (ρυθμίζεται ανά άτομο).
- **Αιτήσεις άδειας** από τους εργαζόμενους → **έγκριση/απόρριψη από τον admin** → εμφάνιση στο **κοινό ημερολόγιο** (ορατό σε όλους).
- **Κανόνες**: μπλοκαρισμένες ημέρες, όχι δύο απόντες ταυτόχρονα από το ίδιο τμήμα, όχι αλληλοκάλυψη με δικές του άδειες, όχι παρελθοντικές ημερομηνίες, έλεγχος υπολοίπου. Μετρώνται μόνο εργάσιμες (εκτός Σ/Κ και ελληνικών αργιών, με υπολογισμό Πάσχα).
- **Έκτακτες άδειες** (αναρρωτική, ασθενείας, μητρότητας/γονική, άλλη): καταχωρούνται από τον admin, εγκρίνονται άμεσα, δεν αφαιρούνται από τις 22 ημέρες.
- **Email στον admin**: νέα αίτηση, και υπενθύμιση πριν από κάθε εγκεκριμένη άδεια (προεπιλογή 7 και 2 ημέρες πριν, ρυθμίζεται).

## Εκτέλεση
```
npm install
ADMIN_PASSWORD=... SESSION_SECRET=... npm start      # http://localhost:3000
npm test
```
Απαιτεί Node ≥ 22.13 (χρησιμοποιεί το ενσωματωμένο `node:sqlite`).

## Ρυθμίσεις (μεταβλητές περιβάλλοντος)
| Μεταβλητή | Περιγραφή |
|---|---|
| `ADMIN_PASSWORD` | Κωδικός admin (υποχρεωτικός σε production). Σύνδεση με χρήστη «Διαχειριστής». |
| `SESSION_SECRET` | Τυχαίο μυστικό για τα sessions (υποχρεωτικό ώστε να μην αποσυνδέονται σε restart). |
| `INITIAL_PASSWORD` | Αρχικός κωδικός των εργαζομένων (προεπιλογή `imentor2026`). Αλλάζουν μόνοι τους ή τους τον ορίζει ο admin. |
| `ADMIN_EMAIL` | Αρχικό email admin (αλλάζει από τις Ρυθμίσεις· προεπιλογή `info@i-mentor.gr`). |
| `DATA_DIR` | Φάκελος βάσης SQLite. **Σε Railway/Docker προσαρτήστε volume** (π.χ. `/data`), αλλιώς τα δεδομένα χάνονται. |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM` | Διακομιστής email. Χωρίς αυτά, τα email εμφανίζονται μόνο στα logs. Για Google Workspace: `smtp.gmail.com`, 587, και App Password. |

Οι ειδοποιήσεις ελέγχονται κάθε 6 ώρες· κάθε άδεια ειδοποιεί μία φορά ανά όριο ημερών.
