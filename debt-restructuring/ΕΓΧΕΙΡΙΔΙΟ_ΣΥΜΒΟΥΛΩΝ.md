## 1. Κατηγορίες οφειλετών

Το εργαλείο διαχωρίζει **τρεις κατηγορίες** με εντελώς διαφορετικούς κανόνες υπολογισμού:

| Κατηγορία | Υποκατηγορία | Κανόνας εισοδήματος |
|---|---|---|
| **Φυσικό Πρόσωπο** | Μισθωτός | Flat — εισόδημα έτους Τ |
| **Φυσικό Πρόσωπο** | Επιτηδευματίας | 3-phase Step-Up (ΚΥΑ 67360 άρθρο 8Α §5) |
| **Νομικό Πρόσωπο** | — | Κέρδη τριετίας (ΚΥΑ 7712925/2025) |

## 2. Υπολογισμός διαθέσιμου εισοδήματος

### 2α. Φυσικό Πρόσωπο — Μισθωτός

**Πηγή δεδομένων:** Εκκαθαριστικό εφορίας (Ε1) — εισαγωγή από σύμβουλο

**Τύπος:**
```
Διαθέσιμο = max(0, Εισόδημα_Τ − Δαπάνες) × 80%  +  Καταθέσεις / 20
```

- Χρησιμοποιείται **μόνο το εισόδημα έτους Τ** (τελευταίο)
- Το ποσοστό 80% εφαρμόζεται ενιαία σε όλες τις φάσεις (flat — χωρίς step-up)
- Καταθέσεις: μόνο το υπερβάλλον ποσό πέραν αφορολόγητου ορίου

**Αφορολόγητο καταθέσεων ΦΠ:**

| Σύνθεση νοικοκυριού | Αφορολόγητο |
|---|---|
| 1 μέλος | 2.000 € |
| 2 μέλη | 3.000 € |
| 3 μέλη | 4.000 € |
| 4+ μέλη | έως 5.000 € (max) |

**Εύλογες δαπάνες (ΕΔΔ) που αφαιρούνται:**

| Δαπάνη | Κανόνας επιμερισμού |
|---|---|
| Ελάχιστες δαπάνες διαβίωσης (ΕΔΔ) | Κλάση × αναλογία οφειλέτη |
| Ενοίκιο | Αναλογία · cap (βλ. §2δ) |
| Ιατρικά | Αναλογία |
| ΕΝΦΙΑ | Πλήρης (χωρίς αναλογία) |
| Ενοίκιο φοιτητή | Πλήρης |
| Διατροφή | Πλήρης |

**Αναλογία οφειλέτη:**
```
Αναλογία = Εισόδημα_οφειλέτη / (Εισόδημα_οφειλέτη + Εισόδημα_συζύγου)
```
Αν δεν υπάρχει σύζυγος: αναλογία = 100%.

---

### 2β. Φυσικό Πρόσωπο — Επιτηδευματίας

**Πηγή δεδομένων:** Αποκλειστικά από πλατφόρμα ΕΓΔΙΧ — πεδίο "Ετήσιο Ατομικό Εισόδημα Οφειλέτη"

**Εισαγόμενα στοιχεία (3ετία):**
- Ατομικό εισόδημα: Τ, Τ-1, Τ-2
- Κύκλος Εργασιών: Τ, Τ-1, Τ-2 (χρησιμοποιείται μόνο ο ΚΕ_Τ για τον υπολογισμό reserve)
- Εισόδημα συζύγου (από ΕΓΔΙΧ)

**Βασικός τύπος Stage 1:**
```
dispFromY1 = max(0, Εισόδημα_Τ − Δαπάνες) × 80%  +  Ελεύθερες_Καταθέσεις / 20
```

**Επιφύλαξη κεφαλαίου κίνησης:**
```
Επιχειρηματική_Επιφύλαξη = max(Αφορολόγητο_ΦΠ, ΚΕ_Τ × 5%)
Ελεύθερες_Καταθέσεις = max(0, Καταθέσεις − Επιχειρηματική_Επιφύλαξη)
```

> Για Επιτηδευματίας εφαρμόζεται ο κανόνας step-up — βλ. §3.

### 2γ. Νομικό Πρόσωπο (ΚΥΑ 7712925/2025)

**Πηγή δεδομένων:** Φορολογικές δηλώσεις 3 ετών

**Βήμα 1 — Ταξινόμηση:**
```
Μικρή ΝΠ: ΚΕ_Τ < 2.500.000 € ΚΑΙ ΚΕ_Τ-1 < 2.500.000 € ΚΑΙ ΚΕ_Τ-2 < 2.500.000 €
           ΚΑΙ τραπεζική οφειλή < 5.000.000 €
```

**Βήμα 2 — Διαθέσιμο ανά έτος:**
```
Διαθέσιμο_χ = max(0, Κέρδη_χ − ΕΝΦΙΑ)
```

**Βήμα 3 — Ταξινόμηση + μέσος όρος:**
```
avg2 = (Υψηλότερο_διαθέσιμο + 2ο_υψηλότερο_διαθέσιμο) / 2
```

**Βήμα 4 — Έλεγχος κατωφλίου 10% (μόνο Μικρή ΝΠ):**
```
Εάν avg2 < ΚΕ_Τ × 10%:
   → Τελικό_Διαθέσιμο = ΚΕ_Τ × 10%   (Ενεργοποιείται κανόνας MAX ΔΟΣΕΩΝ)
Αλλιώς:
   → Τελικό_Διαθέσιμο = avg2
```

**Βήμα 5 — Προσθήκη καταθέσεων:**
```
Ελεύθερες_Καταθέσεις = max(0, Καταθέσεις − ΚΕ_Τ × 5%)
Συνολικό_Διαθέσιμο = Τελικό_Διαθέσιμο + Ελεύθερες_Καταθέσεις × 95% / 20
```

> **Σημείωση:** Για ΝΠ δεν εφαρμόζεται step-up. Το διαθέσιμο είναι ενιαίο για όλη τη διάρκεια.

---

### 2δ. Ανώτατο όριο ενοικίου (ΚΥΑ Παράρτημα παρ. δ)

Το εργαλείο **δεν δέχεται ολόκληρο** το ενοίκιο — εφαρμόζεται cap:

| Μέλη νοικοκυριού | Cap (μηνιαίο) |
|---|---|
| 1 | 350 € |
| 2 | 400 € |
| 3 | 450 € |
| 4 | 500 € |
| 5+ | 550 € (max) |

Τύπος: `Cap = min(350 + (Μέλη−1) × 50, 550)`

Αν το δηλωθέν ενοίκιο > cap, αφαιρείται μόνο το cap.

## 3. Κανόνας Step-Up (μόνο Επιτηδευματίας)

> **Βάση:** ΚΥΑ 67360 άρθρο 8Α §5 | ΦΕΚ Β' 2499/2021 §9

**ΠΡΟΣΟΧΗ:** Ο κανόνας step-up εφαρμόζεται **ΑΠΟΚΛΕΙΣΤΙΚΑ** σε Επιτηδευματίες (ατομικές επιχειρήσεις / αυτοαπασχολούμενους). Δεν εφαρμόζεται σε Μισθωτούς και Νομικά Πρόσωπα.

### 3α. Οι τρεις φάσεις

| Φάση | Μήνες | Διαθέσιμο |
|---|---|---|
| **Stage 1** | 1–12 | `(Εισόδημα_Τ − Δαπάνες) × 80%` |
| **Stage 2** | 13–48 | `max(Stage_1, avg2 × 65% − Δαπάνες × 80%)` |
| **Stage 3** | 49+ | `max(Stage_1, avg2 × 100% − Δαπάνες × 80%)` |

Όπου:
```
avg2 = μέσος όρος των 2 υψηλότερων εισοδημάτων από {Τ, Τ-1, Τ-2}
```

### 3β. Πότε το αποτέλεσμα είναι flat (χωρίς step-up)

Ο νόμος ορίζει **max()** — δηλαδή το μεγαλύτερο των δύο. Αυτό σημαίνει:

**Εάν Εισόδημα_Τ >> avg2** (το τελευταίο έτος ήταν πολύ καλύτερο από τα προηγούμενα):
- Όλα τα max() επιστρέφουν Stage 1
- Αποτέλεσμα: **flat πρόγραμμα** (ίδια δόση σε όλες τις φάσεις)
- Αυτό είναι **νομικά σωστό** — ο νόμος δεν επιβάλλει step-up, επιβάλλει min εγγύηση

**Εάν Εισόδημα_Τ << avg2** (τελευταία χρονιά ήταν κακή/κρίση):
- Stage 2 και Stage 3 δίνουν υψηλότερα ποσά από Stage 1
- Αποτέλεσμα: **γνήσιο step-up** — οι δόσεις ανεβαίνουν στα έτη 2–4 και 5+

### 3γ. Παράδειγμα flat fallback

| Στοιχείο | Τιμή |
|---|---|
| Εισόδημα Τ (y1) | 56.115 € |
| Εισόδημα Τ-1 (y2) | 3.716 € |
| Εισόδημα Τ-2 (y3) | 0 € |
| Δαπάνες | 16.522 €/έτος |

```
Stage 1 = (56.115 − 16.522) × 80% = 31.674 €/έτος → 2.639 €/μήνα
avg2    = (56.115 + 3.716) / 2   = 29.916 €
Raw Stage 2 = 29.916 × 65% × 80% = 15.545 €/έτος → 6.965 €/μήνα (raw)

Επειδή 6.965 < 31.674:
  Stage 2 = max(31.674, 6.965) = 31.674 → 2.639 €/μήνα
  Stage 3 = max(31.674, 10.714) = 31.674 → 2.639 €/μήνα
→ FLAT στα 2.639 €/μήνα
```

**Συμπέρασμα:** Το εργαλείο υπολόγισε σωστά. Step-up δεν προκύπτει όταν το τελευταίο έτος ήταν εξαιρετικά καλό.

### 3δ. Παράδειγμα γνήσιου step-up

| Στοιχείο | Τιμή |
|---|---|
| Εισόδημα Τ (y1) | 8.000 € |
| Εισόδημα Τ-1 (y2) | 45.000 € |
| Εισόδημα Τ-2 (y3) | 40.000 € |
| Δαπάνες | 12.000 €/έτος |

```
Stage 1 = (8.000 − 12.000) × 80% = 0 € (αρνητικό → 0)
avg2    = (45.000 + 40.000) / 2  = 42.500 €
Stage 2 = max(0, 42.500 × 65% − 12.000) × 80% = (27.625 − 12.000) × 0.8 = 12.500 €/έτος → 1.042 €/μήνα
Stage 3 = max(0, 42.500 − 12.000) × 80% = 24.400 €/έτος → 2.033 €/μήνα
→ STEP-UP: 0 → 1.042 → 2.033 €/μήνα
```

## 4. Επιτόκια ρύθμισης

### 4α. Περίοδος promo (μήνες 1–36)

| Κατηγορία | Επιτόκιο |
|---|---|
| Τράπεζα — ενυπόθηκο | **3,00%** |
| Τράπεζα — ανέγγυο | **4,00%** |
| Εφορία (ΑΑΔΕ) | **3,00%** (σταθερό για πάντα) |
| ΕΦΚΑ-ΚΕΑΟ | **3,00%** (σταθερό για πάντα) |

### 4β. Περίοδος post-promo (μήνες 37+) — μόνο τράπεζες

```
Επιτόκιο = Euribor 3M + Spread
```

| Κατηγορία | Spread | Τρέχον επιτόκιο (Euribor 2,16%) |
|---|---|---|
| Ενυπόθηκο | +2,50% | ~4,66% |
| Ανέγγυο | +3,00% | ~5,16% |

> **Euribor** ενημερώνεται χειροκίνητα μετά από κάθε ανακοίνωση ΕΚΤ. Τρέχουσα τιμή: **2,16%** (Q4 2024).

### 4γ. Δόσεις c1 / c2 (step-up τοκοχρεωλύσιο)

Η **δόση c1** (μήνες 1–36) υπολογίζεται με το promo επιτόκιο για ολόκληρη τη διάρκεια.
Η **δόση c2** (μήνες 37+) υπολογίζεται αφού αφαιρεθεί το κεφάλαιο που αποπληρώθηκε στους πρώτους 36 μήνες, με το post-promo επιτόκιο.

```
c1 = PMT(r1, N, Κεφάλαιο)
Υπόλοιπο_36 = Κεφάλαιο × (1+r1)^36 − c1 × [(1+r1)^36 − 1] / r1
c2 = PMT(r2, N−36, Υπόλοιπο_36)
```

> Για δημόσιους πιστωτές (ΑΑΔΕ, ΕΦΚΑ): **c1 = c2** (επιτόκιο σταθερό 3%).

## 5. Μέγιστοι αριθμοί δόσεων

| Κατηγορία | Τύπος | Max Δόσεις |
|---|---|---|
| ΦΠ | Ενυπόθηκο (secured) | **420 μήνες (35 έτη)** |
| ΦΠ | Ανέγγυο τράπεζας | **240 μήνες (20 έτη)** |
| ΦΠ | Εφορία / ΕΦΚΑ | **240 μήνες (20 έτη)** |
| ΝΠ | Ενυπόθηκο | **240 μήνες** |
| ΝΠ | Ανέγγυο τράπεζας | **180 μήνες** |
| ΝΠ | Εφορία / ΕΦΚΑ | **240 μήνες** |

### 5α. Ηλικιακός περιορισμός (ΦΠ μόνο)

```
Max_δόσεις_ηλικία = max(12, (85 − Ηλικία_νεότερου_μέλους) × 12)
Τελικό_max = min(θεωρητικό_max, max_δόσεις_ηλικία)
```

> Παράδειγμα: Νεότερο μέλος 60 ετών → max = (85−60)×12 = 300 μήνες. Για ανέγγυο τράπεζας (θεωρητικό max 240): ισχύει 240. Για ενυπόθηκο (θεωρητικό max 420): περιορίζεται στους 300.

### 5β. Κανόνας 240 MAX ΔΟΣΕΩΝ (Ενεργοποίηση κατωφλίου)

Ενεργοποιείται **μόνο** όταν το υπολογισθέν διαθέσιμο πέφτει κάτω από το ελάχιστο:
- **ΝΠ (μικρή):** Εάν avg2 < 10% ΚΕ_Τ
- **ΦΠ Επιτηδευματίας:** Εάν dispFromY1 < 0% × ΚΕ_Τ (hardcoded 0% → δεν ενεργοποιείται ποτέ)

Αποτέλεσμα: Όλοι οι πιστωτές ρυθμίζονται σε max 240 δόσεις.

## 6. Ανώτατα όρια διαγραφών

### 6α. Τραπεζικά χρέη

| Στοιχείο | Ανώτατη Διαγραφή |
|---|---|
| Κεφάλαιο | έως **80%** (τράπεζα ανακτά ≥ 20%) |
| Τόκοι / προσαυξήσεις | **100%** |

**Σημαντικό:** Η διαγραφή ισχύει **μόνο για το ακάλυπτο μέρος** (uncovered). Εάν η περιουσία καλύπτει το χρέος, δεν προκύπτει διαγραφή.

**Μερικώς ενυπόθηκος κανόνας:** Εάν η καθαρή αξία εξασφάλισης > 20% της οφειλής, η μέγιστη διαγραφή = `max(κανονική, Οφειλή − Καθαρή_Αξία)`.

### 6β. Δημόσια χρέη — γενικός κανόνας

| Στοιχείο | Ανώτατη Διαγραφή |
|---|---|
| Κεφάλαιο | έως **75%** (δημόσιο ανακτά ≥ 25%) |
| Τόκοι / προσαυξήσεις | **85%** |

## 7. Κατηγορίες δημοσίου χρέους

Το εργαλείο υποστηρίζει ανά κατηγορία ανάλυση (ΚΥΑ 13243/2024):

| Κατηγορία | Ποσοστό Διαγραφής | Παραδείγματα |
|---|---|---|
| **Μη διαγράψιμη βασική** | **0%** | ΦΠΑ, ΦΜΥ, παρακρατούμενα · παρακρατ. εισφορές ΕΦΚΑ |
| **Τόκοι μη διαγράψιμης** | **85%** | Προσαυξήσεις/τόκοι επί ΦΠΑ, ΦΜΥ |
| **Λοιπή διαγράψιμη βασική** | **75%** | Φόρος εισοδήματος, ΕΝΦΙΑ, ΓΕΜΗ · εργοδοτ. εισφορές ΕΦΚΑ |
| **Τόκοι διαγράψιμης** | **85%** | Προσαυξήσεις/τόκοι επί παραπάνω |
| **Πρόστιμα ΑΑΔΕ** | **95%** | Φορολογικά πρόστιμα |

> **Σημείωση:** Εάν ο σύμβουλος δεν συμπληρώσει ανάλυση κατηγοριών, το εργαλείο εφαρμόζει τον γενικό κανόνα (75%/85%) στο σύνολο.

## 8. Κάλυψη από περιουσία

### 8α. Υπολογισμός καθαρής ρευστοποιήσιμης αξίας

```
Καθαρή_Αξία = Αξία_ακινήτων × 97%  +  Καταθέσεις_πέραν_ορίου
```

(Αφαίρεση 3% για έξοδα εκποίησης — ΚΠολΔ art.)

### 8β. Κατανομή βάσει ΚΠολΔ 977

**Ενυπόθηκα ακίνητα (ανά ακίνητο):**
```
65% → στον ενυπόθηκο πιστωτή (secured creditor)
10% → στο Δημόσιο (ΑΑΔΕ/ΕΦΚΑ) pro-rata
25% → στους ανέγγυους pro-rata (συμπεριλ. υπόλοιπο ενυπόθηκου)
```

**Ελεύθερα στοιχεία ενεργητικού:**
```
2/3 → στο Δημόσιο pro-rata
1/3 → στους ανέγγυους pro-rata
```

### 8γ. Πότε δεν υπάρχει διαγραφή

- Εάν **καθαρή αξία περιουσίας ≥ σύνολο οφειλών**: κάθε πιστωτής καλύπτεται πλήρως → **μηδενική διαγραφή**
- Εάν η περιουσία καλύπτει το covered μέρος, διαγραφή γίνεται μόνο στο uncovered υπόλοιπο

## 9. Αλγόριθμος εύρεσης λύσης

### 9α. Φάση 1 — Greedy month extension (dual constraint)

Το εργαλείο ξεκινά από **12 δόσεις** ανά οφειλέτη και επεκτείνει greedy:

**Δύο περιορισμοί ταυτόχρονα:**
- `Σύνολο c1 ≤ monthlyDisp1` (δόση promo ≤ διαθέσιμο Έτους 1)
- `Σύνολο c2 ≤ monthlyDisp24` (δόση post-promo ≤ διαθέσιμο Ετών 2–4)

Σε κάθε βήμα επιλέγει **ποιον πιστωτή να επεκτείνει** κατά 1 μήνα, ώστε να μειωθεί η παραβίαση του πιο καταπονημένου περιορισμού.

### 9β. Φάση 2 — Binary search διαγραφών

Εάν μετά τη μέγιστη επέκταση το πρόβλημα παραμένει μη εφικτό (δόσεις > διαθέσιμο):
- Δοκιμάζει κλίμακες διαγραφής από 0% → 100% (βήμα 1%)
- Βρίσκει το ελάχιστο ποσοστό διαγραφής που κάνει τη λύση εφικτή
- Η κατανομή γίνεται **pro-rata** βάσει ανώτατων ορίων ανά πιστωτή

### 9γ. Φάση 3 — Μηδενικό εισόδημα

Εάν το διαθέσιμο = 0:
- Όλοι οι πιστωτές λαμβάνουν **μέγιστη νομική διαγραφή** και **μέγιστες δόσεις**

### 9δ. Post-processing κανόνες

- **Ενήμερες οφειλές:** Δεν λαμβάνουν διαγραφή (writeoff = 0)
- **Ελάχιστη μηνιαία δόση:** 50 € ανά πιστωτή (εάν η δόση είναι μικρότερη, μειώνεται η διάρκεια)

## 10. Πρόταση Α vs Αντιπρόταση πιστωτών

### 10α. Τι παράγει το εργαλείο

Το εργαλείο προσομοιώνει την **αυτοματοποιημένη πρόταση** του αλγορίθμου της πλατφόρμας ΕΓΔΙΧ (Πρόταση Β — ΚΥΑ 13243/2024).

Αυτή η πρόταση:
1. Υιοθετείται αυτόματα από **ΑΑΔΕ και ΕΦΚΑ**
2. Αποστέλλεται προς τις **τράπεζες** για αποδοχή ή αντιπρόταση

### 10β. Συντηρητικό σενάριο (Αντιπρόταση)

Το εργαλείο εμφανίζει και **συντηρητικό σενάριο** που προσομοιώνει την αντιπρόταση πιστωτών. Βασίζεται σε εμπειρικούς συντελεστές (ενημέρωση βάσει κλεισμένων υποθέσεων):

| Κατηγορία | Συντελεστής συντηρητικού |
|---|---|
| ΑΑΔΕ / ΕΦΚΑ | **100%** (δεν αλλάζει — νομικά δεσμευτικό) |
| Τράπεζα ενυπόθηκη | **65%** της υπολογισθείσας διαγραφής |
| Τράπεζα ανέγγυη | **75%** της υπολογισθείσας διαγραφής |

> Παράδειγμα: Πρόταση Α για ανέγγυη τράπεζα: διαγραφή 100.000 €. Αντιπρόταση (συντηρητικό): διαγραφή 75.000 €.

### 10γ. Τι γίνεται στην πράξη

```
Αυτοματοποιημένη πρόταση (εργαλείο)
        ↓ αποστέλλεται στις τράπεζες
Τράπεζα ΑΠΟΔΕΧΕΤΑΙ → Εφαρμόζεται πρόταση Α
Τράπεζα ΑΝΤΙΠΡΟΤΕΙΝΕΙ → Νέα διαπραγμάτευση
        (συνήθως δυσμενέστερη για τον οφειλέτη)
```

## 11. Σενάρια αποτελέσματος

Το εργαλείο κατατάσσει αυτόματα κάθε υπόθεση σε ένα από τα εξής σενάρια:

| Σενάριο | Ονομασία | Συνθήκες |
|---|---|---|
| **1** | Οικονομικά Ισχυρό Προφίλ | Εισόδημα επαρκεί · δεν απαιτείται διαγραφή |
| **2** | Δυνητικό "Κούρεμα" | Εισόδημα επαρκεί μετά από μερική διαγραφή |
| **3** | Ισχυρό Δικαίωμα Διαγραφής | Εισόδημα ανεπαρκές · μέγιστη διαγραφή |
| **4** | Χαμηλό Εισόδημα · Πλήρης κάλυψη | Εισόδημα ανεπαρκές · περιουσία καλύπτει όλα |
| **5** | Χαμηλό Εισόδημα · Μερική κάλυψη | Εισόδημα ανεπαρκές · περιουσία μερική |

**Λογική:**
```
lowIncome = ratio5 > 100%   (δόση > διαθέσιμο Ετών 5+)

Σενάριο 1: δεν απαιτείται διαγραφή ΚΑΙ εισόδημα OK
Σενάριο 2: απαιτείται διαγραφή ΚΑΙ εισόδημα OK μετά
Σενάριο 3: απαιτείται διαγραφή ΚΑΙ εισόδημα ΔΕΝ επαρκεί
Σενάριο 4: lowIncome ΚΑΙ περιουσία ≥ χρέη
Σενάριο 5: lowIncome ΚΑΙ 0 < περιουσία < χρέη
```

## 12. Ηλικιακό όριο αποπληρωμής

- Ισχύει **μόνο για Φυσικά Πρόσωπα**
- Στηρίζεται στην ηλικία του **νεότερου μέλους** νοικοκυριού
- Ανώτατο όριο ηλικίας: **85 έτη**

```
Max_χρόνια = 85 − Ηλικία_νεότερου_μέλους
Max_δόσεις = max(12, Max_χρόνια × 12)
```

> **Παράδειγμα:** Νεότερο μέλος 70 ετών → max 180 μήνες (15 έτη) για ενυπόθηκο (αντί 420).
